This directory is intentionally empty.

Wireframes are a **planning artefact** and may only be created after:

1. the information architecture in `docs/02-product-and-ux/` is approved by
   Jacob, and
2. Jacob writes the exact phrase `AUTHORISE WIREFRAME ONLY`.

Even then, only a static or mock-data prototype is permitted — no backend, no
database, no broker connection, no secrets, no publishing access, and no live
actions of any kind. Wireframe approval is **not** implementation
authorisation (see root `CLAUDE.md`).
